# Excel 产品导入

在“产品导入”页选择 xlsx → 读取文件 → 检查预览和错误 → 确认导入。
只读取第一张工作表；第一行为机器字段名，空白行跳过。
必填字段沿用模板并增加 keywords、description 的非空检查。可选字段列可省略。
价格及重量使用 Decimal；MOQ 为正整数。价格、重量须非负且有限。
币种当前支持 USD、CNY、EUR、GBP、JPY、HKD、AUD、CAD；其他值拒绝导入。
不支持未知列、重复列名、公式及 Excel 错误值。
编号文本保留前导零；整数数字编号转字符串，纯零数字格式可恢复显示前导零；Excel 已丢失且无格式记录的零无法恢复。
使用 read_only 流式读取及 QThread；最多读取 100000 个数据行，累计 1000 条错误停止校验。整批存在错误不能确认保存。
取消通过协作标志停止；读取线程结束前关闭主窗口会暂缓，避免线程被销毁。
产品仅在点击确认后原子追加到本次会话内存，已有编号冲突整批拒绝。退出软件后数据丢失。
工作台、产品管理页仍为第三阶段模拟展示，本页内存结果尚未同步到这两页。
本阶段无数据库、不检查图片目录内容、不连接或上传到客户端。
macOS 离屏测试不替代原生桌面、Windows 实机和超大文件性能实测。
