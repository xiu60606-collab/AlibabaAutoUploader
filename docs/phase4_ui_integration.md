# 第四阶段界面集成

主界面版本 v0.3.0，保留六页导航和整体布局。
工作台/产品管理均使用 SQLite 快照，无模拟产品正式展示；空库显示零行和零统计。
后台线程读取产品和图片校验数据，完成后统一更新两张 QTableView、产品选择框与统计；并发刷新请求合并为后续刷新。
产品管理支持编号/标题搜索、校验状态筛选、点击选择和双击编辑详情；编辑和导入成功自动刷新。
工作台待处理数暂定义为全部本地产品（尚无上传任务模块）；通过/失败仅为本地通用数据校验，不是上传成功。
导入页支持 Excel 文件选择、产品预览、错误说明、确认和图片根目录选择。图片根目录在当前会话共享，未持久化，重新启动需重新选择。
未选择图片根目录时会报告图片校验失败，不推断图片有效。图片数量在选定根目录后按有效本地图片统计；未选根目录时显示已保存图片元数据数量。
本阶段后台处理读取和批量校验；数据库写入/编辑保存仍同步，极大批次写入响应优化未完成。
Windows 和原生 macOS 视觉效果未实测；无真实自动上传。
