# 产品编辑与通用校验

产品管理页从已导入数据库产品下拉列表选择产品，选择图片根目录，再点击“查看 / 编辑选中产品”。
编辑窗口展示所有模板字段；产品编号只读，其余字段可编辑。图片支持设主图和调整顺序，点击保存统一提交 SQLite。取消关闭丢弃该窗口草稿，不修改数据库或原始图片。
图片扫描完成前暂缓保存/关闭。修改 image_folder 后如与预览图片不一致，保存会拒绝；请保持目录字段与实际图片一致。

校验规则在 core/product_validation.py，通过额外规则函数可扩展类目校验；当前只是本地通用规则，不是阿里巴巴官方完整发布规则。
检查必填字段、非空编号及标题、正价格、正整数 MOQ、图片目录/文件存在性、格式和损坏。批量检查列出每个产品的错误数量及具体原因，并检查输入批次重复编号；数据库唯一约束继续阻止编号重复。
保存前从磁盘重新校验图片，不信任缓存。数据和图片元数据在同一事务提交；并发资料变化则拒绝保存，异常回滚。
现有 Excel 导入规则仍允许价格 0；该产品在本次编辑/通用检查中会报错，不能作为通用校验通过的产品保存。

批量检查当前同步执行，图片较多时可能等待；尚未做大规模性能验证。检查结果仅展示，不持久化错误数量。
工作台与原表格仍为明确标注的模拟数据，编辑入口对应数据库产品下拉列表。
图片绝对路径元数据仅适用于本机；跨机器迁移需重新选择根目录并保存。
macOS 离屏自动测试不替代原生桌面和 Windows 实机验收。
