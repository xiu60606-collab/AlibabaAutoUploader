# 本地产品图片管理

先在产品导入页确认 Excel 导入，再进入产品管理页，选择已导入产品及图片根目录。
上方原有表格仍为模拟数据；新增下拉列表对应真实内存导入产品。
image_folder 严格相对于所选图片根目录。例如根目录为 ProductImages 时填写 P001；若填写 ProductImages/P001，则选择 ProductImages 的父目录为根目录。

校验 JPG/JPEG/PNG/WEBP 扩展名与实际解码格式一致性、文件存在性、可解码性、非空且不超过 20 MiB、像素不超过 4000 万。
以上大小限制为当前本地检查默认值，不代表平台上传规格。
按文件名自然排序；有效图片显示数量、缩略图，可选择预览、设主图、前移后移。主图默认第一张有效图片。
失败项显示文件名及具体原因；无有效图片明确提示。图片检查在后台线程运行，检查期间暂缓关闭窗口。
禁止绝对路径、Windows 驱动器路径、.. 和符号链接目录/文件；解析后再次验证目录位于图片根目录内。
原图仅只读打开；640×640 以内预览图、顺序、主图都仅存在内存，不修改或删除原始图片。切换根目录会清空检查缓存，退出后丢失设置。
当前仅扫描产品子目录直接文件，不递归扫描。目录内容应在扫描期间保持不变；尚未实现针对恶意并发替换文件的操作系统级隔离。

测试：Python 3.13.12 / macOS，pytest 离屏。原生桌面和 Windows 实机视觉验证仍待完成。
